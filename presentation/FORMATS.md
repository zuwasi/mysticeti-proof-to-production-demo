# Presentation formats

The Mysticeti Consensus Digital Twin presentation is delivered in three formats:

1. PowerPoint
   - `Mysticeti_Consensus_Digital_Twin_ESL.pptx`
2. PDF
   - `rendered/Mysticeti_Consensus_Digital_Twin_ESL.pdf`
3. Interactive HTML
   - `html/index.html`

Open `html/index.html` in a modern browser. The HTML presentation supports:

- left/right arrow keys, Page Up/Page Down, Space, Home, and End
- touch swipe and desktop mouse drag
- navigation buttons
- a fixed, accessible Home button on every slide
- progress bar and slide counter
- fullscreen mode with the `F` key
- responsive mobile layout
- clickable ESL and LinkedIn links

The HTML package includes its 22 slide images under `html/slides/` and can be hosted as a static website without a server-side application. The deck includes the bounded Rust architecture, causal network behavior, actual Windows/Ubuntu WSL evidence, byte-identical cross-OS and jobs=1/jobs=8 hashes, the deterministic parallel 20-seed/80-row campaign, and a three-lane Rust/Wolfram/Lean release gate.
